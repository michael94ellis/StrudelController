# Beat Studio

Layered beat / music maker powered by [Strudel](https://strudel.cc) (`@strudel/web`).

## License

**AGPL-3.0-or-later** — required when integrating Strudel.

## Develop

```bash
npm install
npm run dev
```

Open the local URL, click **Play**, then tweak layers (drums, bass, keys, melody, texture), vibe presets, key, and BPM.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- Zustand
- Lucide React
- `@strudel/web`

## Notes

Existing Strudel track sketches (`cozy-village-morning.js`, `cozy-restaurant-tutorial.js`) seeded the vibe presets.
